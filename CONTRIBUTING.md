# Contributing

Read [agents.md](agents.md) and [arhitecture.md](arhitecture.md). Install with `npm ci`, run the development server with `npm run dev`, and make a focused change. Keep the educational simulation disclosures accurate.

Before submitting, run `npm test`, `npm run test:e2e`, and `npm run build`. Update the relevant documentation and record meaningful changes in `progress.md`. Keep generated output and credentials out of commits. Pull requests run the same checks as the deployment workflow.
